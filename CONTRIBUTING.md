# Contributing to rover-ops

This is a guide on how you can contribute your own code to the project using Git and GitHub.

## Development Workflow
We follow the GitHub Flow development workflow for simplicity. Read more about GitHub flow [here](https://docs.github.com/en/get-started/using-github/github-flow).

1. **Create a branch**

    Create a branch off the `main` branch with a short descriptive name:
    * `fix/fix-description` (for bug fixes)
    * `feat/feature-description` (for new features)
    * `chore/chore-description` (for refactoring, dependencies, docs, etc.)
    
    *Note: ONE feature or fix per branch. New feature = new branch.*

2. **Commit changes**

    Please use descriptive commit messages when committing your changes. For example:
    * `fix: resolve incorrect thrust calculations`
    * `feat: add login button`
    * `chore: update npm to 24.14.0`

3. **Submit a Pull Request (PR)**

    * Create a pull request against the `main` branch
    * Fill out the required fields in the pull request template
    * Write bullet points on what changed, features added, etc.
    * Tag a lead and/or another teammate for review before merging
